## Decisions locked (don't re-litigate)

- Money is **integer pesewas** everywhere, never floats
- Only the **webhook** issues tickets; the redirect callback is UX only
- Overselling is prevented **in the database**, not in application code
- **SMS is primary** for broadcasts; WhatsApp is template-only
- Scanner is **online-only**; short code in the message text is the connectivity fallback
- No programmatic refunds in v1 — void + `refunded_at` record only
- Buyers never sign up; tickets are authorized by unguessable `qr_token`

## Open risks being carried

- Paystack Ghana verification is the real critical path (test keys only today)
- Moolre API contract unverified — cost and endpoints unknown until the docs are read
- Late webhook after hold expiry can take money with no ticket left → manual resolution
- MoMo latency (60–120s) causes buyer retries and double-payment
